# CLAUDE.md — Pathways USA

Pathways USA is a free U.S. citizenship test prep app (civics, reading, writing, speaking, N-400 guide). It was built in Base44 and exported to this repo.

## Rules (always follow)

### Legal and content
- Pathways USA is a free education app, **not a legal service**. Nothing may tell a learner how THEY should answer an N-400 question about their own history, or whether THEY are eligible. Point legal questions to the "Talk to a lawyer first" section of the Resource Hub (`src/pages/LawyerPage.jsx`, `/lawyer-first`).
- Official civics questions and answers come from the app's USCIS question lists (`CivicsQuestion` records, versions `2008` and `2025`). AI may **explain** them but must never change, add, or invent official answers.

### Privacy
- Never store a learner's immigration status, A-number, case details, filing date, field office, address, or N-400 answers.
- A learner's location (browser location or typed ZIP on the Resource Hub) is used on the device only, to sort places by distance: never saved, never in a URL, never sent to the AI or Base44.
- No audio or speech transcripts are stored; only scores.
- The learner's target date lives **only** in browser storage on their device (wrap every `localStorage` read/write in try/catch).
- Learner text (typed or spoken-as-text) goes to the AI only in the features the AI Policy describes: Ask Vía, civics answer grading, interview/lesson answer scoring, and the representative lookup (zip, plus a street address only when the zip spans several districts). Never with personal identifiers (email, name), never saved, and emails/phone numbers are stripped first where learners type freely. Check answers on the device first when that's enough.

Soft tints `pw-soft`, `pw-*-soft` remain for light backgrounds. Use tokens, not one-off hex colors.
- **Building blocks** in `src/components/pathways/ui.jsx`: Tag, SkillTag, SkillDot, SegmentedProgress, PrimaryButton, SecondaryButton, QuietButton, PillButton, RaisedCard, Eyebrow, plus `PathwaysMark` (`size`, `tone` ink|white; heavier geometry at ≤ 24px), `PathwaysLockup` (horizontal|stacked, optional descriptor), `ViaMark` (decorative unless labeled), `IndexCard` (radius 14, optional colored tab and thin red top rule), `Poster` (full-bleed red|blue block, white text; alternate with `posterTone(index)`, scheme constant in `src/lib/posterTone.js`), `Folder` + `FolderTab` (manila, N-400 only), `FormQuote` ("ON THE FORM · WORD FOR WORD", "— Form N-400, item {n}") and `ExplainSimplyButton` ("Explain it simply"). Cards are white with a `pw-line` border and `shadow-raised` / `shadow-lift` (`shadow-card` is not usable: it collides with the `card` color). Line drawings are navy (`src/components/art/TopicArt.jsx`); their red dot is off by default (`accent` prop) so a screen keeps only the logo's and Vía's dots, and there is no flag drawing (`road` and `map` replace it). Headlines (page titles and section h2s) use `font-display`; focus rings are navy. The shadcn components in `src/components/ui/` and their CSS variables in `src/index.css` match the kit; `PageHeader` takes `tag`, `tagTone`, and `art`. The official N-400 form replica (`src/components/n400/N400PaperForm.jsx`, `form/`) intentionally keeps its own look (`font-typewriter`). `npm run lint` is clean; keep it that way.
- **Brand rules**: the name is Pathways; never "official", USCIS branding, seals, eagles, flags, shields, torches or the Statue of Liberty. Where the brand meets the public, show "Free practice · Not affiliated with USCIS". The red dot is the single accent per view: the Pathways logo dot and Vía's dot may share a screen, no other Signal-red decor there.
- **The tutor front and center**: the AI tutor (default "Vía") is the learner's teacher: introduces themself to new learners on Home (`TutorIntro.jsx`), sits in the middle of the phone tab bar and in the desktop "Ask Vía" button (both open `StudyBuddy`; other code can call `openTutorChat()`), and says what each page is for via `PageHeader`'s `guide` prop (`TutorLine.jsx`). `useTutorProfile()` is loaded once and shared, so using it in many places is cheap. **Vía is always the V mark** (`ViaMark`, shown by `TutorAvatar`), whatever name the learner picks: never a face, photo or portrait, labeled "{name} · AI tutor". Show the mark **once per screen**: the center of the tab bar (or the desktop Ask button, or the Getting started welcome on focus screens). Everywhere else the tutor signs in text, "— {name}" in Instrument Serif italic (`TutorLine`, `TutorMessage`, `TutorIntro`, the setup preview); the "You're here" stop on the Home path is a navy marker. Old portrait choices (`tutor_profile.avatar`) are ignored, not migrated; any old device photo (`pathways_tutor_photo`) is deleted once on load (`clearTutorPhoto()`, `src/lib/tutorPhoto.js`). `TutorAvatar`/`TutorMessage` still accept `expression`, but it no longer changes anything. **Read aloud**: on focus routes (onboarding, quick check, lessons) every `TutorMessage` reads itself aloud when it appears (learner's language, then English; skips a language the device has no voice for), shows Stop while speaking, and keeps Listen for replay. Logic in `src/lib/autoRead.js` + `src/components/persona/useAutoRead.js` (`AutoReadContext` set in `Layout.jsx`); the first message waits for the learner's first tap (browser rule). Microphones call `stopReading()` before listening. Learners turn it off in Getting started or Profile (`pathways_auto_read`, device only).
- **Landing**: signed-out visitors see the splash, `StartHereCard` (stacked logo, "Free U.S. citizenship test practice", Vía's hello signed "Vía · AI tutor", "Start here" → sign in → Getting started + quick check, and "Free practice · Not affiliated with USCIS", also in the footer); new learners see `TutorIntro`, whose "Your first step" box makes the quick check the one thing to tap. The language menu sits at the top of Home, above the first card.
- **Navigation**: phones get a bottom tab bar (`src/components/pathways/TabBar.jsx`): Today · Lessons (`/Lessons`) · tutor (V mark, labeled with the tutor's name) · Practice · N-400; the desktop nav also says "Lessons" and the header shows `PathwaysLockup`; Progress, My Classroom, Profile are in Menu. Lesson screens (`FOCUS_ROUTES` in `Layout.jsx`) hide the tab bar and chat button.
- **Skill colors**: one subject color per interview skill, `SKILL_TONE` / `SKILL_BG` / `SKILL_COLOR` / `SkillTag` / `SkillDot` in `ui.jsx` (civics `pw-civics`, reading `pw-reading`, writing `pw-writing`, speaking `pw-speaking`, N-400 navy). Use them for anything tied to a skill.
- **Contrast** (≥ 4.5:1 for all text): `pw-red` (#D9483F) is for the dot and small decor only, never text; red text, red buttons with text, and red posters use `pw-red-ink` (hover `pw-red-deep`). White on Red ink ≈ 5.6:1, on Civics ≈ 8.5:1. Hover shades are tokens too (`pw-navy-deep`, `pw-soft-hover`).
- Mobile-first at 360px wide. Buttons at least 44px tall. Body text at least 16px.

### Tutor tone
- Respectful and adult. No cartoon mascots, leaderboards, hearts/lives, or punishing streaks.

### How to work
- Change only what a prompt asks. Show a plan before changing code.
- Test with fake information only.

## Stack

- **React 18 + Vite**, JavaScript (JSX), Tailwind CSS, shadcn/ui (`src/components/ui/`), lucide icons, TanStack Query, react-router.
- **Base44** is the backend: `@base44/sdk` client in `src/api/base44Client.js`, plus `@base44/vite-plugin`.
  - **Data**: Base44 entities, defined in `base44/entities/*.jsonc`, used as `base44.entities.<Name>.list/filter/create/update`. Records (including the civics question bank, interview questions, reading/writing sentences) live in the Base44 database, not in repo files.
  - **Access rules**: each entity file has an `rls` block. Content (questions, sentences, lessons, vocabulary) is public to read and admin-only to change. Learner records are owner-only (`data.user_email` = the signed-in email); `Message` is sender/receiver, `Assignment` tutor/student (created only by the `tutor-link` function, for the tutor's active students), `TutorRelationship` tutor/student to read or delete and created/changed only by the `tutor-link` function. Admins get no extra access to learner data. Keep stored emails lowercase so the rules match. A new entity with no `rls` is open to every user.
  - **Auth/user**: `base44.auth.me()` / `base44.auth.updateMe()` (the `User` entity holds extra fields).
  - **Backend functions**: `base44/functions/<name>/entry.js` (shared code in `base44/shared/`), called with `base44.functions.invoke(name, data)`. `tutor-link` makes every tutor ↔ student link change (invite, request, join by code or confirmed invite link, accept/decline by the person who didn't send it) and sends assignments (`assign`, active students only) and `student-progress` gives a tutor their actively linked students' progress; client helpers in `src/lib/tutorLinks.js`. The app never writes `TutorRelationship` directly.
  - **AI**: `base44.integrations.Core.InvokeLLM({ prompt, response_json_schema?, file_urls?, add_context_from_internet? })`. Also `SendEmail`, `UploadFile`.
- **AI tutor persona** (default name "Vía"; not the human tutor in My Classroom): config and `buildTutorInstructions()` in `src/lib/tutorPersona.js`; UI in `src/components/persona/`.
- **Tutor lessons**: `TutorLesson` (`src/components/persona/`) renders a lesson = `{ id, title, steps }`; step types and rules in `src/lib/tutorLesson.js`. Practice checks are shared: `checkCivicsAnswer()` (`src/components/civics/`, AI, spoken answers) and `checkDictation()` / `matchOfficialAnswer()` (`src/lib/practiceChecks.js`, on-device, for typed answers). Feedback always shows official accepted answers from the question bank, never AI-written ones. Admin-only demo at `/tutor-demo`. Step types also include `part-intro` (skippable parts), `practice-reading`, `practice-interview`, and `mode: 'check'` (record the answer, no teaching).
- **Quick check (pretest)**: `/quick-check` (`src/pages/QuickCheck.jsx`); lesson building and level cutoffs in `src/lib/pretest.js`. Only the four levels are saved (`User.skill_levels`). `?part=<skill>` re-checks one skill and keeps the others. The first time on a device, **Getting started** comes first (`GettingStarted.jsx`, logic in `src/lib/onboarding.js`): a Start tap (lets the browser speak; shows Vía's mark), language, tutor name (suggestions in `SUGGESTED_TUTOR_NAMES`, `tutorPersona.js`), where they are in the process, which civics test (only if applied; stores the test version, never a date), interview month (only if scheduled; reuses `PlanSetup`), then sound and text size. Answers are device-only except the tutor name. New students go here right after picking the student role.
- **Study plan + Today (Prompts 5, 6, 8)**: pure plan logic in `src/lib/studyPlan.js`, device-only settings in `src/lib/planSettings.js` (target date, plan mode, checkmarks, visits), check-ins in `src/lib/checkIns.js`; UI `TodayCard.jsx` / `PlanSetup.jsx` in `src/components/persona/`, text in `todayStrings.js`. Today is laid out as X2 (layout helpers in `src/lib/todayView.js`): the learner's stage chip (device-only Getting started answer), "Good evening, {first name}." (sign-in name, shown only, never translated or sent to the AI), Vía's line in serif italic signed "— Vía", a stack of index cards on Slate (top = the next unfinished task with a subject tab and Start), "Also today" cards with DONE/FILED stamps, and the week as seven squares plus readiness; "about N weeks" shows only when an interview month is set. No countdown, no streaks. Task links: `/learn`, `/review`, `/Practice?mode=reading|dictation|civics|interview`, `/n400-coach?section=…`.
- **Teach then practice (Prompt 7)**: `/learn` and `/review` (`src/pages/LearnCivics.jsx`, `ReviewCivics.jsx`). Explanations are content in `content/explanations/{lang}.json`; only `"reviewed"` entries are shown (`src/lib/explanations.js`). Workflow: Admin → export questions → draft → human review (`content/explanations/REVIEW.md`); `npm test` fails if an explanation's answers differ from `content/civics/questions-2025.json`. Explanations may use line breaks (intro + one `• answer: …` line per answer for list questions) and an optional `link` to an official site (shown as a Listen button). "Answers change" questions show the admin-confirmed names in `content/civics/current-officials.json` (Admin → Current officials: AI checks uscis.gov, the admin confirms and commits the file); "Answers vary" questions show the learner's own Find My Representative result. Logic in `src/lib/currentAnswers.js`.
- **Lessons (Phase 4)**: `/Lessons` (`src/pages/Lessons.jsx`) is a card box on Slate: one colored divider per official topic with "n of m lessons" (`LessonProgress.completed`), lesson index cards behind it. A lesson (`src/components/lessons/LessonDetail.jsx`) is a deck with segmented progress (`src/lib/lessonDeck.js`): **Watch** (`video_url`, skipped if none) → **Learn** (key points and the text split one idea per card, `GlossaryText`, key-point definitions behind "Explain it simply", the existing translation) → **Key words** (`LessonFlashcard` flip cards) → **Questions on the test** (the lesson's official questions and answers in English) → **Go over them** (`PosterRun.jsx`: red/blue posters, spoken answers via `checkCivicsAnswer()`, typed via `matchOfficialAnswer()` on the device, "Explain it simply" = reviewed explanation only) → done card (score, `LessonNotes`, next lesson). A lesson's questions are its topic's `CivicsQuestion`s matched to the lesson by shared words (`src/lib/lessonQuestions.js`, no extra data; each question goes to one lesson). Official questions/answers are never sent for translation. Saves only `LessonProgress` (completed, scores). `/learn` and `/review` pass `posters: true` to `TutorLesson`, so their civics questions show on posters too.
- **Practice (Phase 5)**: `/Practice` (`src/pages/Practice.jsx`) hub = four part cards (Civics, Reading, Writing incl. vocabulary games, Speaking) with alternating red/blue strips, plus "Mixed practice" (links to the Interview Day run-through). Every item renders as a `Poster` (`index`/`total` props → color via `posterTone`, "PRACTICE · CARD 2 OF 6", `PosterSquares`): `CivicsTestCard`, `ReadingPracticeCard`, `DictationCard` (`src/components/game/`), and the current question in `InterviewPractice`. Feedback stays on the poster ("Answer: …" in serif italic, official answers only); reading and writing keep the word-by-word check (`wordDiff`, `checkDictation`). "Explain it simply" opens `ExplainSheet` (reviewed explanation; the civics card's existing on-demand AI explanation only as fallback). Interview personal/morals questions (`isUnderstandingSection`) are never answered: the learner says what the officer is asking and `evaluateUnderstanding()` (`evaluateInterviewAnswer.js`) checks only understanding, with "Talk to a lawyer first" on the poster. No practice people. Poster buttons: `posterSolid` / `posterOutline` in `ui.jsx`. Modes and `?mode=` params, `testMode` (Interview Day) and the `InterviewSession` rules are unchanged.
- **N-400 coaching (Prompt 9)**: `/n400-coach` (`src/pages/N400Coach.jsx`, `src/lib/n400Lesson.js`, steps in `src/components/persona/n400Steps.jsx`); the practice round is understanding only (`n400-understand` steps: the officer's phrasing, the learner says what it asks, `evaluateUnderstanding()` with the plain meaning). No practice people anywhere. Saves only section completion.
- **N-400 folder (Phase 6)**: `/n400-guide` (question guide view) and `/n400-coach` use the manila `N400Folder` (`src/components/n400/N400Folder.jsx`): one colored `FolderTab` per section (Part 8, then the Part 9 groups), the open section's title and part, and "n of 7 sections read" (`N400SectionProgress`). The guide keeps the open section in `?section=`; coach tabs open that section's lesson. Each question card (`N400QuestionCard.jsx`) shows the form wording in `FormQuote` ("ON THE FORM · WORD FOR WORD", "— Form N-400, item {label}"), then "Explain it simply" revealing the plain meaning, words to know and officer phrasings from `n400Content.js` verbatim, Say it back, "Talk to a lawyer first" and "We never save your answers to the N-400." The "Example applicants" view and the paper-form replica are unchanged.
- **Interview Day**: `/interview-day` (`src/pages/InterviewDay.jsx`, `src/components/interview-day/`, rules in `src/lib/interviewDay.js` incl. `CIVICS_TEST_RULES`): a "what to expect" guide plus a full rehearsal (oath → Mock Interview questions, with the application questions understanding-only → reading → writing → civics → results). Reuses `InterviewPractice` (`rehearsal` prop: no `InterviewSession` save, no report) and the reading, dictation and civics cards (`testMode` prop: one try, no reveal/translate). **Saves nothing**: no entity writes, no browser storage (the daily reminder is not mounted on this page).
- **Ask Vía + Talk to a person (Prompt 10)**: `src/components/ai/StudyBuddy.jsx` (a `Sheet`: full screen on phones, side drawer on desktop; header = Vía's mark + "{name} · AI tutor"; Vía's replies in Instrument Serif italic), `TalkToPerson.jsx`, logic in `src/lib/askTutor.js`. Support email and reply time live in `src/config/support.js` (form disabled until both are set).
- **Privacy audit**: `docs/privacy-audit.md` (Prompt 11).
- **Resource Hub**: `/resources` (also `/lawyer-first`, which scrolls to the lawyer section), page `src/pages/LawyerPage.jsx`. "Find help near you" (`src/components/resources/ResourceFinder.jsx`; map `ResourceMap.jsx` is lazy-loaded Leaflet with OpenFreeMap "Positron" vector tiles via MapLibre (free, no key; worker bundled with `?worker&url`), falling back to paler USGS National Map tiles without WebGL; OSM's volunteer tile servers block apps and CARTO needs a key. Pins are colored by category (`PIN_COLORS`) and grouped with `leaflet.markercluster` (needs `leafletGlobal.js`); the map shows every place in range, the list 30 at a time; "Search this area" re-centers on the map; full-screen mode with a swipe-up list) lists `CommunityResource` places (categories: legal, esl, citizenship_class, uscis, library, other) near the learner. Logic and import cleaning in `src/lib/resourceHub.js`; ZIP coordinates from the bundled Census table `src/data/zipCentroids.json`. A place has one main `category` plus a `services` list (filters match any; `placeServices()`), optional `hours`, `logo_url` (shown only in the pin summary, `PlaceSummary.jsx`) and an `external_id` (`nld:…`, `doj:…`, `uscis:…`). Places are human-checked listings only (never AI-found), managed in Admin → Places (add/edit/hide, CSV/JSON import that adds new places and updates matching ones via `planImport()`; format in `content/resources/README.md`). Places that aren't relevant are hidden, not deleted, with the reason in `relevance_note`.
- **Pages** are auto-registered from `src/pages/` (`src/pages.config.js` is auto-generated; only `mainPage` is editable). `src/Layout.jsx` wraps all pages. Feature components live in `src/components/<area>/`.
- **Speech**: browser Web Speech API (`SpeechRecognition`, `lang = 'en-US'`) produces a transcript; scoring is word matching (`src/components/utils/wordDiff.js`) plus an `InvokeLLM` evaluation. Text-to-speech: `src/components/utils/textToSpeech.jsx` (`speakText(text, lang)`).
- **Languages/i18n**: no i18n library. The chosen language is `localStorage['pathways_language']` (`src/hooks/useAppLanguage.js`; list in `LANGUAGES` in `src/hooks/useLessonTranslation.js`). UI strings are written in English and translated on demand with `InvokeLLM`, cached per language in localStorage (`useHomeTranslation`, `useN400Translation`, `useLawyerChecklistTranslation`). RTL languages: `ar`, `fa`, `ur`, `he`.
- **Build/deploy**: `npm run dev`, `npm run build`, `npm run lint`, `npm test` (Vitest; tests are `src/**/*.test.js`, config in `vitest.config.js`). The live app runs on Base44: this repo is two-way synced with Base44 on `main`, so **merging to `main` updates the live app**. Work on branches and merge via pull request. Running locally needs the Base44 env vars (`VITE_BASE44_APP_ID`, `VITE_BASE44_BACKEND_URL`).

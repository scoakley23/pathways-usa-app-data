# "The Road" redesign: screenshots

Every main screen at 390 px wide (2x), taken for the final check (Prompt 10) so
they can be compared with the Round 4 and Round 5 boards on the design canvas.

- **Test data only.** A local harness replaces Base44 with fake records (the
  learner "Ana Test", made-up lessons and sentences) and a fake AI reply. No
  real account, learner or answer appears.
- `01`–`23`: the main screens in English.
- `rtl-…`: the same screens with the app language set to Arabic (right to
  left). The fake AI returns no Arabic text, so some lines stay in English or
  Spanish; with real translations they are in Arabic.
- A recorded microphone, real translations and real accounts were not used;
  check those on a phone before cutover.

Needs native speakers. I picked these marks from each language's own letters or accents, but I'm not an expert in all 16. Each one needs a native-speaker check before launch, especially Korean, Punjabi, Bengali, Urdu and Persian, which don't use accent marks the way Spanish does.
Beyond 16. The app has 62 languages. Any language without its own mark shows the plain dot, so it's never left blank. Marks can be added one at a time.
